# ЛофтЭхо — главная страница

Эталонная вёрстка главной страницы караоке-клуба «ЛофтЭхо» по макету Figma.
Сделана как референс для разработчика: показывает, как должны работать все механики,
которые дизайнер описала в макете заметками **«Note for Dev»**.

Живая версия: https://claude.ai/code/artifact/affcf42b-a75b-4eb5-9177-81dfa80d3476

Макет: Figma `216ao8wLnj6rFmwRGWNpp2`, главная — нода `6701:18067`.

---

## Как открыть

Просто откройте `dist/index.html` двойным кликом. Это один самодостаточный файл:
ни сборки, ни сервера, ни интернета (кроме Google Fonts) не требуется.

## Как пересобрать

```bash
python3 build.py
```

Собирает `dist/` из файлов в `src/`. Больше ничего не нужно — ни npm, ни бандлера.

На выходе: `index.html` (главная), `paket-<slug>.html` (9 страниц пакетных предложений
из `src/packages.json`), общий `images.css` с фото (подключается всеми страницами с меткой
версии `?v=`), и `artifact.html` — главная одним файлом для Claude Artifact.
Страницы пакетов собираются из разделов главной (`2-body.html` размечен комментариями
`<!-- ════════ ИМЯ ════════ -->`) плюс два своих раздела: первый экран и цены.

## Структура

```
src/
  1-head.html     <title>, подключение шрифтов, ВСЕ стили
  2-body.html     разметка + спрайт иконок, выгруженных из Figma
  3-script.html   вся логика: скролл-эффекты, слайдеры, шейдер, карта, модалки
  images.css      все фотографии в виде data-URI (см. «Про картинки»)

assets/
  svg/            исходные иконки из Figma
  map/            перекрашенные тайлы карты + метаданные точки клуба

tools/
  encode.py       пережимает фото из assets/raw в src/images.css
  build_map.py    заново собирает карту по координатам клуба

build.py          сборка dist/ из src/
dist/             результат
```

## Что здесь реализовано (заметки «Note for Dev» из Figma)

| Заметка в макете | Где в коде |
|---|---|
| «Фон — слайдер с эффектом Ken Burns» | `@keyframes kb`, 5 залов, цикл 45 с |
| «Карточка 1 фиксируется (position: sticky), карточка 2 подъезжает снизу» | `.room-slot{position:sticky}` |
| «Карточка 1 уменьшается (Scale down до ~0.9) и уходит в тень» | цикл по `slots` в `frame()`: scale 1 → 0.9 + затемнение 0 → 0.55 по прогрессу перекрытия |
| «Верхний и нижний ряды скроллятся вправо, средний — влево, линейно» | класс `Marquee`, три трека |
| «При наведении движение всей карусели ставится на паузу» | `mqs.forEach(m => m.target = .08)` — замедление до 8 %, не полная остановка |
| «При ховере появляется ссылка на страницу пакетного предложения» | `.combo-link`, по центру карточки, как в компоненте `Card/Promo` |
| «Читать все отзывы — ссылка на Яндекс.Карты» | `#revAll` |
| Sticky Image + Scrolling Content | `#featsTrack` высотой 280vh, `featSet(i, frac)` |
| Modal/Room Details, Modal/Gallery Fullscreen | `#modRoom`, `#modGal` |

### Сверх макета — переходы изображений

Смена фото в блоке «О караоке» и в слайдерах залов идёт через WebGL-шейдер
(`Fx` в `3-script.html`): органическое растворение по fbm-шуму со смещением
обеих картинок и световой вспышкой по шву. Шесть независимых контекстов,
рисуют только во время перехода. Если WebGL недоступен — автоматический
откат на CSS-кроссфейд.

## Про картинки — важно для продакшена

**Здесь все фото зашиты в CSS как base64 data-URI.** Это не рекомендация,
а вынужденная мера: страница живёт как Claude Artifact, а там CSP режет любые
внешние запросы (кроме Google Fonts). Отсюда `src/images.css` на 4 МБ.

**На реальном сайте так делать не надо.** Замените переменные `--i-*` на обычные
файлы:

```css
/* было */
--i-kosmos: url("data:image/webp;base64,UklGR...");
/* стало */
--i-kosmos: url("/img/rooms/kosmos.webp");
```

Разметка и логика при этом не меняются вообще — всё обращается к фото только
через `var(--i-имя)`. Оригиналы лежат в Figma, пережимает их `tools/encode.py`
(там же таблица «имя → исходник → размер → качество»).

## Про карту

В макете карта — скриншот Яндекса с золотым стилем. Живой виджет Яндекса внутри
артефакта запустить нельзя: это внешний скрипт, его блокирует CSP. Поэтому здесь:

* реальные тайлы OpenStreetMap по адресу клуба
  (Колокольников пер., 22 с5 → **55.767908, 37.629301**);
* перекраска под палитру макета (`tools/build_map.py`, LUT + отдельная
  обработка подписей по их белому ореолу);
* два уровня зума, перетаскивание мышью, пин на нужном здании;
* атрибуция OpenStreetMap — обязательна по лицензии ODbL, не удаляйте.

**На проде** ставьте `api-maps.yandex.ru` с ключом и JSON-стилем в этих же цветах —
фон `#5b4820`, дороги от `#967C3E` до `#ECDCB4`, подписи `#EEE2C0`.

## Что осталось за скобками

* **Третий слайд в блоке «О караоке».** В макете три сегмента индикатора,
  но описаны только два состояния. Третий («Уют и приватность залов») собран
  из данных клуба — нужен текст от дизайнера.
* **Отзывы.** В макете шесть точек пагинации, реальных отзыва три — используются
  только они, карусель зациклена. На проде подтянутся с Яндекс.Карт.
* **Цены в модалке зала.** Разбивка «Пн-чт / Пт-вс» в макете есть только
  у Тропиков, поэтому везде показаны документированные значения с карточек.
* **Ширина заголовков в акциях.** Google-версия Roboto Flex рисует кириллицу шире,
  чем сборка в Figma. Слова догнаны до точной ширины текст-нод масштабом по X
  (`--sx` у `.offer-word`). Если у дизайнера есть исходный файл шрифта — подставьте
  его и уберите `--sx`.
